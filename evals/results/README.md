# Eval results

One JSON file per eval run: model, effort, the checks and the full transcript of every agent run.

**These files contain fictional road data.** Most scenarios change Vegagerðin's conditions snapshot to create test cases (invented closures, warnings and injected text; see `evals/scenarios.py`). Don't read any of it as real road conditions.

Source data: Vegagerðin, `faerd2017_1` snapshot generated 2026-11-06, CC BY 4.0. See `../../DATA_LICENSE.md`.
